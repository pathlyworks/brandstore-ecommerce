# web/ — the React app (wave 0 skeleton)

The React + TypeScript app the migration plan builds next to the legacy pages ([`task_1_architecture.md`](../task_1_architecture.md) §3).
This is the wave 0 skeleton: the routing map as route objects (layout, nested routes, 404), the cart in Context with
`useReducer`, and Tailwind with the brand tokens. The routes are placeholders that say which wave migrates them.

```
npm install
npm run web:dev         # http://localhost:5173
npm run web:typecheck
```
